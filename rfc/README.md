# The UN-RFC Series

The Unseenet protocol is specified here, in numbered documents in the
tradition of the Internet RFCs that defined Usenet. The documents are the
authority; any implementation that follows them can join the network.

Start with [UN-RFC 0000](un-rfc-0000.md) (the process) and
[UN-RFC 0001](un-rfc-0001.md) (architecture). The full index is in
UN-RFC 0000, section 6.

To propose a change, open an issue describing the problem, then a pull
request adding a new Draft UN-RFC with the next free number.
