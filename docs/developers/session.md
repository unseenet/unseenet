# Session reference

`Session` (`unseenet.client.session`) is one class. Its code is written in
parts by area, and this page follows them: each part says what belongs in it,
then lists its functions. **All of them are called on a `Session`**, for
example `s.subscribe(group)`, whichever part they are written in.

Generated from the docstrings in the code; functions whose name starts with
`_` are internal and not shown.
