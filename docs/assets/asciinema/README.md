# asciinema player

`asciinema-player.min.js` and `asciinema-player.css` are
[asciinema-player](https://github.com/asciinema/asciinema-player) 3.17.0
(`dist/bundle/` from the npm package), licensed under Apache-2.0 - see
`LICENSE`. They are kept here, not loaded from a CDN, so reading the docs
makes no requests to other sites. `docs/javascripts/demo.js` uses them for
the recording on the front page (`docs/img/demo.cast`, made with
`tools/docs_recording.py`).
